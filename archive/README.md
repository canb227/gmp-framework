# Archive

Content set aside but kept for later. The `.gdignore` here hides this folder from Godot, so nothing in it is
imported, loaded or checked.

- `museum/`: the Object Museum level (`ObjectMuseum.tscn`) and its wing scenes (`museum/*.tscn`), archived
  2026-10-09. To restore, move `ObjectMuseum.tscn` back to `game/scenes/levels/` and the `museum/` folder to
  `game/scenes/levels/museum/`, then re-add it to `GameResources.LevelsList`.
